# 吳興福音醫院概況

《吳興福音醫院概況》記述浙江吳興福音醫院 1929 年度的院史、組織章程、董事及職員、護士學校、就診統計、收支和院舍計畫。底本為中國國家圖書館 08jh014197／37820，資料含 49 幅掃描定位與逐格表格。

A source-linked transcription of the 1929 overview of Wuxing Gospel Hospital, including its organizational rules, personnel and nursing school, statistical reports, financial accounts and proposed buildings.

- 原刊由吳興福音醫院編纂，刊次 民國十八年度（1929），浙江吳興。共 49 幅，依底本分幅定位。 [館藏／原件](https://commons.wikimedia.org/?curid=131010099)
